# The whole app is a public portfolio demo with no promise of upkeep

The RefCycle whole-app build runs publicly so anyone can try it, but it is a portfolio demo, not a service for residents. Rules packs, facility lists and dependencies are not kept current after the build, and the app says so. We chose this over a maintained public app because nobody is committed to verifying three places' recycling rules over time, and a stale answer presented as current would break the eval's core promise of no confident wrong answers.

Decided by Kiley Sullivan, 2026-11-11, in the scope grill for the Fable 5.2 build.
