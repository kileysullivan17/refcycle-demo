# The public demo calls the model live, behind a hard daily spending cap

Every search and scan in the hosted demo calls the model with Kiley's provider key, so a public link carries real cost and abuse risk. We chose a live demo with a hard daily spending cap and a per-visitor limit, over a live search-only demo or a recorded walkthrough, because a working, capped app is stronger proof of the build than a video. The key stays server-side, never in the browser.

Decided by Kiley Sullivan, 2026-11-11, in the scope grill for the Fable 5.2 build.
